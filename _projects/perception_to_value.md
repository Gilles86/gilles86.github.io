If limited neural resources shape how we represent numbers, the same should hold
for other quantities, and for later stages of the decision process. In work led by
Saurabh Bedi, we asked whether perception
and valuation each have their own efficient code.

{% capture description %}
By varying how stimulus orientation maps onto value, we could tease apart efficient
codes in perception and valuation (Bedi et al., 2026).
{% endcapture %}

{% include image.html url="/assets/imgs/publications/2026/sequential_representations.png"
description=description width="50" %}

 * **Perception and value have separable codes.** In a preregistered study, behavior was best explained by efficient coding at both stages, each tracking its own prior. Changing the value distribution even reversed the classic repulsion biases of orientation perception. Perceptual codes reflected stable, long-term structure, while value codes updated rapidly with context ([Bedi et al., 2026, preprint](https://doi.org/10.64898/2026.06.08.730978)).
 * **Probability distortions come from noise near boundaries.** People overweight small and underweight large probabilities because cognitive noise is repelled by the natural boundaries of probability, 0 and 1. Three preregistered experiments confirmed the predictions of this account ([Bedi, de Hollander & Ruff, 2025, preprint](https://doi.org/10.1101/2025.09.11.675565)).
 * **Value itself has a population code.** The OFC/vmPFC implements a probabilistic population code for value, and its decoded uncertainty predicts preference instability and confidence ([Le Bouc et al., 2026, preprint](https://doi.org/10.64898/2026.03.28.715037)).

We are now studying how these codes change as people learn what stimuli are worth.
